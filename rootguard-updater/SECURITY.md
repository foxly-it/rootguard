# Security policy

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting for
[`foxly-it/rootguard-updater`](https://github.com/foxly-it/rootguard-updater/security/advisories/new)
when available. If the report affects the complete appliance, use the private
reporting channel of the
[`foxly-it/rootguard`](https://github.com/foxly-it/rootguard) project.

Include the affected version or commit, deployment context, reproduction steps,
and expected impact. Do not include real credentials, tokens, DNS queries, or
private configuration data.

Only the latest published pre-release is actively evaluated during alpha
development. A formal supported-version window will be defined before stable
1.0.
