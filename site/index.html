Quick Start · Docker Compose

In wenigen Minuten startklar.

Du brauchst Docker Compose und einen Rechner im Heimnetz. Lade die fertige Alpha, trage ein eigenes Passwort sowie zwei zufällige Sicherheitsschlüssel ein und starte den Stack.

  1. 01
    Dateien ladenCompose und Beispielkonfiguration herunterladen.
  2. 02
    Zugang absichernPasswort und getrennte API-/Recovery-Schlüssel in .env setzen.
  3. 03
    Stack startenWeboberfläche öffnen und dem geführten Setup folgen.
Vollständige Anleitung und Voraussetzungen →
rootguard-alpha
mkdir rootguard-alpha && cd rootguard-alpha

curl -LO https://raw.githubusercontent.com/foxly-it/rootguard/v0.1.0-alpha.6/compose.alpha.yaml
curl -Lo .env https://raw.githubusercontent.com/foxly-it/rootguard/v0.1.0-alpha.6/.env.alpha.example

# .env sicher ausfüllen

docker compose -f compose.alpha.yaml up -d

Was RootGuard für dich übernimmt

Einfacher Schutz für alle Geräte.

RootGuard bündelt bewährte Open-Source-Technik in einer verständlichen Oberfläche. Du behältst die Kontrolle, ohne jedes technische Detail kennen zu müssen.

01

Stört weniger

Werbung und bekannte Tracker werden zentral blockiert, bevor sie deine Geräte erreichen.

02

Schützt deine Anfragen

DNS-Anfragen werden im eigenen Stack verarbeitet und mit DNSSEC auf Manipulation geprüft.

03

Bleibt unter deiner Kontrolle

Dashboard, Konfiguration und Updates laufen auf deinem eigenen Docker-Host.

Dokumentation

Vom ersten Checkout zum DNS-Stack.

Der aktuelle Entwicklungsstack ist für Tests und Mitarbeit gedacht. Er ist noch keine Empfehlung für den produktiven DNS-Betrieb eines gesamten Netzwerks.

quickstart.sh
# Öffentliche Alpha-Compose laden
mkdir rootguard-alpha && cd rootguard-alpha
curl -LO https://raw.githubusercontent.com/foxly-it/rootguard/v0.1.0-alpha.6/compose.alpha.yaml
curl -Lo .env https://raw.githubusercontent.com/foxly-it/rootguard/v0.1.0-alpha.6/.env.alpha.example

# API- und Recovery-Token getrennt erzeugen
openssl rand -hex 32
openssl rand -hex 32
docker compose -f compose.alpha.yaml up -d

# WebApp öffnen, anmelden und Setup ausführen
open http://localhost:8080/login
Wichtig: Setze ein starkes Admin-Passwort sowie getrennte zufällige API- und Recovery-Token. Die Alpha lädt fertige Images für amd64 und arm64, ist aber noch nicht für den Einsatz in Produktivumgebungen vorgesehen.

RootGuard wächst schrittweise zu einem sicheren, wartbaren Gesamtsystem. Die Reihenfolge priorisiert verlässlichen Betrieb vor zusätzlichen Komfortfunktionen.

    Funktionaler Alpha-KernAIO-Setup, DNS-Kette, Login, Unbound-Lifecycle und Update-Grundlagen
