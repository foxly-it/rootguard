Quick Start · Docker Compose

In wenigen Minuten startklar.

Du brauchst Docker Compose und einen Rechner im Heimnetz. Lade die fertige Beta, trage ein eigenes Passwort sowie zwei zufällige Sicherheitsschlüssel ein und starte den Stack.

  1. 01
    Dateien ladenCompose und Beispielkonfiguration herunterladen.
  2. 02
    Zugang absichernPasswort und getrennte API-/Recovery-Schlüssel in .env setzen.
  3. 03
    Stack startenWeboberfläche öffnen und dem geführten Setup folgen.
Vollständige Anleitung und Voraussetzungen →
rootguard
mkdir rootguard && cd rootguard

curl -LO https://raw.githubusercontent.com/foxly-it/rootguard/v0.1.0-beta.7/compose.release.yaml
curl -Lo .env https://raw.githubusercontent.com/foxly-it/rootguard/v0.1.0-beta.7/.env.release.example

# .env sicher ausfüllen

docker compose -f compose.release.yaml up -d

Was RootGuard für dich übernimmt

Einfacher Schutz für alle Geräte.

RootGuard bündelt bewährte Open-Source-Technik in einer verständlichen Oberfläche. Du behältst die Kontrolle, ohne jedes technische Detail kennen zu müssen.

01

Stört weniger

Werbung und bekannte Tracker werden zentral blockiert, bevor sie deine Geräte erreichen.

02

Schützt deine Anfragen

DNS-Anfragen werden im eigenen Stack verarbeitet und mit DNSSEC auf Manipulation geprüft.

03

Bleibt unter deiner Kontrolle

Dashboard, Konfiguration und Updates laufen auf deinem eigenen Docker-Host.
