RootGuard

Warum wurde diese Website blockiert?

RootGuard verbindet AdGuard Home mit einem eigenen rekursiven Unbound-Resolver. Bevor eine Verbindung überhaupt zustande kommt, prüft AdGuard Home jede DNS-Anfrage gegen Filterlisten und blockiert bekannte Werbe-, Tracking- und Bedrohungsdomains.

Typische Gründe für eine Blockierung

  • Werbung / Tracking – Domains, die Anzeigen ausliefern oder das Surfverhalten protokollieren.
  • Malware – Inhalte, die dein Gerät infizieren können.
  • Phishing – Versuche, Zugangsdaten oder persönliche Daten zu stehlen.
  • Kompromittierte Server – gehackte Webseiten, die unbemerkt Schadcode verbreiten.
  • Manuelle Regel – vom Administrator gezielt gesperrt.

Kann das ein Fehler sein?

Ja, Fehlalarme können vorkommen. Wenn du sicher bist, dass die Seite harmlos ist, kann der Administrator die Filterregeln in AdGuard Home prüfen und bei Bedarf eine Ausnahme hinzufügen.
