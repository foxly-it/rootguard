# Security Policy

Do not report vulnerabilities in public issues, discussions, or pull requests.
Use GitHub
[Private Vulnerability Reporting](https://github.com/foxly-it/rootguard-unbound/security/advisories/new).

Include the affected image tag, architecture, prerequisites, reproducible
steps, impact, and a suggested fix when available. Remove private environment
details from logs.

RootGuard is in public alpha. Security fixes target current images and the
latest published RootGuard alpha.
